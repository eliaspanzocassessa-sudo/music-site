🎵 Elias Cassesse - Music Universe Website 🎵
=============================================

A beautiful, modern, and interactive music website dedicated to Elias Cassesse. This site celebrates music in all its forms and provides an immersive experience for music lovers worldwide.

## Features ✨

- **Stunning Header**: Featuring "ELIAS CASSESSE" prominently at the top
- **Music Genres Showcase**: Explore 6 major music genres with detailed descriptions
- **Iconic Artists**: Discover profiles of legendary musicians across different genres
- **Curated Playlists**: 4 carefully curated playlists by Elias Cassesse
- **Smooth Navigation**: Seamless scrolling between sections
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Animations**: Engaging scroll animations and interactive effects
- **Modern Aesthetics**: Spotify-inspired color scheme with gradient accents

## Technology Stack 🛠️

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with gradients, animations, and flexbox/grid layouts
- **JavaScript**: Interactive features and smooth scrolling

## Sections 📑

1. **Header**: Navigation bar with links to all sections
2. **Hero**: Eye-catching welcome section with call-to-action button
3. **Genres**: Grid showcasing popular music genres (Rock, Classical, Hip-Hop, Pop, Jazz, Blues)
4. **Artists**: Profiles of iconic musicians (David Bowie, Beethoven, Billie Holiday, The Beatles)
5. **Playlists**: 4 curated playlists with thematic descriptions
6. **About**: Information about Elias Cassesse and his music philosophy
7. **Footer**: Links and copyright information

## Design Highlights 🎨

- **Color Scheme**:
  - Primary: `#1db954` (Spotify Green)
  - Secondary: `#191414` (Dark)
  - Accent: `#1ed760` (Bright Green)
  - Gradients: Purple-to-Pink and Purple-to-Violet

- **Typography**: Clean, modern sans-serif fonts with proper hierarchy
- **Spacing**: Well-balanced padding and margins throughout
- **Hover Effects**: Interactive card transitions and scale animations
- **Responsiveness**: Mobile-first approach with breakpoints at 768px and 480px

## How to Use 🚀

1. Open `index.html` in your web browser
2. Navigate through sections using the navigation menu
3. Click cards to see interactive effects
4. Use the "Start Exploring" button to jump to the genres section
5. Enjoy the smooth scrolling animations!

## Files 📄

- `index.html` - Main HTML structure
- `styles.css` - Complete styling and responsive design
- `script.js` - Interactive features and animations

## Customization 🎧

You can easily customize:
- Artist and playlist information in `index.html`
- Colors by editing CSS variables in `styles.css`
- Add more content by duplicating existing cards
- Modify animations by updating keyframes in `styles.css`
